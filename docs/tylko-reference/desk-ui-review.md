## 남은 차이 — 완료 아님

1. 원본은 클릭한 연필 주변에 popup을 둔다. 현재 비펀은 데스크톱 뷰어 하단/모바일 하단 고정. 정확한 앵커 위치와 원본 썸네일 순서·세부 도식 추가 대조 필요.
2. 가격/구매 영역은 기존 사업 규칙 미연결 상태를 유지. 가짜 가격/장바구니 버튼을 추가하지 않았다.
3. 헤더·뷰어 비율, 글꼴·세부 여백·카메라·재질까지 전체 화면 동치는 미완료.
4. 완전히 닫힌 수납 구성에서 원본 후판 버튼의 disabled 정책은 미확인. 기존 제약 유지.
5. Modern 색상 순서·혼합색 스와치 표현과 전체 제품군 공통 시각 토큰은 Claude UI 후속 범위.

공통 ui/furniture-panels 소스는 이번 리더 수정에서 건드리지 않았다. 소유 범위는 team-tasks의 R4 책상 UI 절을 따른다.
