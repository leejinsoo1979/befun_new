## 비교 규칙

정식 사례 `pattern-005/006/007`: 레퍼런스와 Befun viewport를1220×882로 맞추어 저장했다. 정확 카메라·재질 매핑은 맞추지 못했다. Befun 치수는 어두운 사각 라벨이며 레퍼런스의 회색 둥근 라벨과 다르고 내경 높이의 배치도 다르다. 레퍼런스와 모델 화면 스케일·높이·배경이 달라 전체 픽셀 오차를 계산하지 않았다. 뒷판 선택 후 Befun 모델 화면 위치 변화도 관찰하여 카메라 재정렬 조건을 추후 조사한다.

구조 비교와 이미지 비교 결과를 따로 남긴다. 동일 viewport·카메라·선택/hover 상태·치수 표시·재질·배경을 맞춘 후 비교한다. 조건이 다르면 이미지 차이를 기하 오차로 단정하지 않는다. 스크린샷은 `screenshots/<case-id>-reference-front.png`, `...-befun-front.png`에 저장하고 측정하지 못한 카메라 값은 null로 둔다.

## 치수·발 후속 / mosaic-001

불투명 검정 치수 박스를 반투명 회색 둥근 캡슐+흰 글씨로 교체. AO에서 제외되는 billboard mesh를 사용하며 화면상 글자 크기를 유지한다. Mosaic는 실제 clear cell 폭/높이를 표시하고, 병합78·분할18cm 표기를 확인. 외경 가이드는 실제 생성 bodyHeight를 사용한다. 정면에서 겹치는 깊이 가이드는 숨기고 회전 시 표시한다. 정확 글꼴/픽셀/전환 시점 동치는 아직 미측정.

모든 스타일의 발 위치 입력을 실제 렌더 판재로 통합했다. Mosaic는 공개 Type02 함수와 비교했으며, 다른 스타일은 기존 등간격 어긋남을 수정한 것으로 전체 Tylko 동치를 주장하지 않는다. 원본 short_leg.glb 크기는 미측정.

## 최종 재질·화면 확인 — material-source-001 / mosaic-001

- 단색 base/edge RGB와 LAMINATE roughness0.7, metalness0, envMapIntensity0.78을 연결했습니다. 단색에 기존 임의 노이즈 텍스처가 섞이지 않도록 제거했습니다.
- 견본 및 옵티마이저 색상도 같은 팔레트를 사용합니다. 레퍼런스 견본 SVG 자체의 픽셀 일치는 검증하지 않았습니다.
- 최종 Chrome 정면 캡처에서 검정 치수 상자는 없고 회색 반투명 캡슐/흰 숫자가 표시됩니다. 부분 뒷판, 18/38/78cm 내경, 하단 판재 축을 따르는 발을 확인했습니다.
- 화면의 테라코타가 레퍼런스보다 어둡게 보입니다. 렌더 색상 입력값은 일치하지만 현재 광원/환경맵/톤매핑은 다릅니다. 색상값을 임의로 밝게 바꿔 차이를 숨기지 않았습니다. Natural 무늬, 합판 엣지, 카메라, 조명은 별도 미완료입니다.
