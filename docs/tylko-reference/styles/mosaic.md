# Mosaic

2026-10-13 / codex-analysis. Type02 기본 열린 구조를 구현 중이며 전체 동치는 미완료.

## 확인된 사실

근거: `mosaic-001`, `mosaic-source-001`. UI Mosaic는 PORTO에 대응한다. 부분 뒷판은 난수가 아닌 행·열 설계표(2699~2708)의 모듈 종류에서 정해진다. 뒷판 Ohne/OFF에서도 이 기본 뒷판은 유지된다. 얇은 후면 보강대로 대체하지 않는다.

- 판 두께18mm, 열 축 폭은 전체폭−18mm. 좁은 축 폭191mm.
- 폭 범위가 열 수를 고르고, 밀도는 동일 폭 배열과 양 끝의 좁은 열 배열 사이를 보간한다.46~54%는50%로 취급한다. 누적 축 좌표는mm 정수 내림이다.
- 행별1143=개방,1146/1147=뒷판이 있는 연결 모듈,1150=뒷판과 추가 가로판 모듈.38cm 행의1150은18cm 표시 두 칸을 만든다.
- 두 열린 행의1147은 아래 경계를 제거해78cm 표시 개구부를 만든다. 하드웨어에 따른 예외는 아직 전부 구현하지 않았다.
- 세로판은 가로판이 닿는 높이에서 끊는다. 양옆 모두 가로판이 없는 경계는 세로판을 병합하는 예외가 공개 생성기에도 있다.

## 가로판 분절

셀 경계와 제조 부재 분절은 별도이다. 연속 가로판이2400mm를 **초과**하면 세로판 축±9mm 후보로 분절 경로를 만든다. 병합 칸의 없는 가로판 높이는 건너뛴다. 체결 금지 영역, 세로판 교차,1600mm 시야 기준 비용과 대체 두 경로를 반영한다. 임의 균등 분할이나 보기용 검은 선을 추가하지 않는다.232cm 사례에는 길이 기준 분절이 없다.

`reference-horizontal-splits.ts` 독립 해석기를 동일한 분절 전 구조에 대해 공개 함수와1216회 비교해 경로 차이0건. 이것은 입력 구조 자체의 Tylko 동치를 입증한 것이 아니다. 긴 다리/걸레받이 제외.

## 조절발

하단 세로판 중심이 후보이며 모든 발을 등간격으로 놓지 않는다. Type02 깊이32/40cm의 끝단·전후 inset25mm,깊이24cm는20mm. 간격599mm 초과 시 중간 지지점을 추가하는 예외가 있다.232cm·69%의 X(왼쪽에서mm)는25,429,849,1160,1470,1890,2295; 각X의Z는25/295mm.288개 설정에서 공개 함수와 X/Z 일치. 발 원본 모델 형상·노출 높이는 미측정.

## 반영·남은 범위

칸을 채우던 직육면체를 제거하고 실제 판재/부분 뒷판/추가 선반/병합 개구부로 교체. 치수는 실제 clear cell에서 표시. 가로판 분절은 실제 PanelData 부재를 분리하므로 CNC 입력에도 전달된다.

미확인: 다른 제품군, 문·서랍 배치와 병합 조건,18/28cm fill 모듈, 모든 경계/복귀/초기 상태, 전체 형상 오라클, 화면 색·조명·카메라 픽셀 동치. 이전450cm 탐색은 정식 회귀 정답으로 쓰지 않는다.
