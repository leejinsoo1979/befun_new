### 현재 메시 자체의 간섭 재현

GuideScene Housing의 끝캡: 중심 z=13.7, 크기 [8.6,11.6,1] → 바깥 모서리 x=4.3,z=14.2. 슬롯 폭9.4, 길이30 → 끝 원호 중심 z=10.3, 반경4.7. 모서리까지 거리 sqrt(4.3²+3.9²)=5.805… >4.7. 즉 현재 메시끼리도 약1.105mm의 원호 반경 초과가 있다. 실제 제품 공차가 아니라 **현재 코드 도형의 불일치**다. 하우징의 매입 깊이 범위 안에서도 발생한다.

## 맞는 내용과 남은 확인을 분리

- V-1230P의 PH/PC/PH 조합, R의 PH/RC/RH 조합 및 P의 누름 체결과 R의 진입 후 슬라이드라는 큰 순서는 공식 설치도와 부합한다.
- R 공식 설치도는 해제 이동에 15mm를 표시한다. 현재 releaseTravel=15를 근거 없는 숫자라고 단정하지 않는다. 다만 조립/해제의 부품별 방향 및 홈 내부 맞물림은 별도 검증해야 한다.
- V-1230의 길이30, 폭9.4, 깊이12.5±0.5, 커터 이동20.5–20.7은 도면 표기와 대조했다. P/R 권장 간격은 각각 다르다. 이 숫자들이 외관/CAD 전체를 정의하지 않는다.
- MPR은 프로파일 공구번호를 받는 구조다. 화면의 단순 장공이 잘못됐다는 사실만으로 실제 프로파일 공구 가공도 동일한 직선벽이라고 단정하지 않는다. 공구 프로파일/진입·복귀/현장 설정은 여전히 확인 대상이다.

## 우선 수정 요청

codex-assembly는 신규 기능 확장과 별도로 **현재 OVVO 모델의 외형/간섭 수정**을 우선 처리할 것. 기존 활성 잠금을 존중해 리더가 GuideScene.tsx를 동시에 덮어쓰지 않았다. 도면 옆에 현재 부품 단품·착좌 단면·R 진입/슬라이드 장면을 나란히 비교해 제출한다. 같은 코드 상수에 대한 자기 일치 테스트만으로 통과하지 않는다. 3D 재현과 제조 가공 승인 상태를 분리한다.

이 문서는 오류 확정과 수정 요청이며 수정 완료 보고가 아니다. 앱 소스 변경 없음. 원본 PDF/렌더/JSON 경로 및 코드 도형 계산만 검증했다.
