## 상태 전환 실험 (아직 완료 아님)

각 실험에서 전체 옵션·행별 편집·필요 초기 상태를 함께 저장한다.

1. A→B→A: 칸 수/좌표/span/hardware가 원상복귀하는가.
2. 같은 목표를 밀도→너비와 너비→밀도 순서로 도달한다.
3. 행 추가 후 삭제, 행 높이 변경 후 복귀, 재질 변경 후 복귀를 비교한다.
4. 스타일 왕복 때 너비·밀도·행 높이·뒷판·문·서랍·개별 편집·카메라 보존 여부를 각각 기록한다.
5. 새로고침 전후와 다른 시작 디자인에서 같은 옵션을 비교한다. URL 편집 반영 여부도 확인한다.
6. 숨은 seed/template가 의심되면 관찰된 후보만 기록하며 임의 seed를 정답으로 넣지 않는다.

## 사업 규칙 결정 대기

정식 사례 갱신: `pattern-005/006`에서 너비30·높이43·깊이40·밀도2를 고정하고 뒷판만 변경했을 때 한 칸의 내경26×38 표시는 유지되고 뒷판이 생겼다. `pattern-007`은 너비 버튼7회로30→37을 확인했다. 이 사례에서의 버튼 단위는1cm이다. 보편 제약·제품군 전체 규칙으로 확대하지 않는다.

공개 소스 `reference-source-001`에 Pattern 뒷판 행과 스냅 활성화 시 밀도 보정 분기가 존재한다. 현재 제품에 적용되는지 미확인이므로 '뒷판은 구조를 절대 바꾸지 않는다'는 전제를 두지 않는다.

가격 산정, 할인, 배송, 결제, 주문 데이터 호환성은 별도 결정 사항이다. 기하 변경으로 패널 수가 달라질 경우 기존 견적 영향은 보고하되 Tylko의 가격을 이식하지 않는다.

## Mosaic 뒷판 / mosaic-001

Ohne/OFF도 설계표에 지정된 기본 부분 뒷판을 유지한다. 전체 뒷판 ON과는 구분한다. 현재 Type02 기본 열린5행×38cm 사례 확인; 다른 행 높이·하드웨어·마감 조합은 미확인.

## 재질 팔레트 — material-source-001

- Type02 단색은 공개 렌더 RGB를 사용합니다. Terracotta `#954227`, Midnight Blue `#101323`, Burgundy `#4C1414`. 전체 목록은 사례 JSON 및 reference-colors.ts에 있습니다.
- 단색16종과 대비 엣지3종을 연결했습니다. 같은 Terracotta가 두 색으로 보이던 기존 키는 같은 값으로 정규화합니다. 선택지에서 빠진 오래된 저장 색상은 기존 팩토리로 읽으며 Tylko 대응을 추정하지 않습니다.
- Type01 Classic5색은 평면/뒷판 값만 확인했습니다. 합판 엣지는 기존 별도 텍스처를 유지하며, Natural 재질과 동일성은 미확인입니다.
