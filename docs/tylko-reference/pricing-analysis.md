## 추정·한계

두 Club 표시가격은 각각 일반가격×0.62를 정수 반올림한 값과 일치한다. 이 사례의38% 할인 가설일 뿐 전체 제품/국가/시점 공통 규칙이나 정확한 반올림 순서로 확정하지 않는다. 뒷판138€도 이 구성의 총 차액이며 장당 고정단가가 아니다. 공개화면만으로 비공개 서버의 원가/마진/가격표를 정확히 복원한다고 보장할 수 없다.

## 조사 순서

1. 국가/통화/제품군/관찰시각/일반가격/Club·프로모션/전체 편집 상태를 고정·기록한다. 가격 로딩 완료 후 읽는다.
2. 너비1cm 변경과 패널 분절·칸 수 경계 전후; 높이·깊이·밀도는 각각 별도로 비교한다.
3. 같은 형상에서 재질·색상, 뒷판 한 칸, 도어 한 개, 양개 도어, 서랍, 다리 유무·색상 차액을 확인한다. 구조가 함께 바뀌면 복합변경으로 표시한다.
4. 부품 수·면적·길이·가공·하드웨어 항목별 합산 모델과 구간별 가격표 가설을 비교한다. 브랜드 마진/최소가격 등은 확인 없이 숫자를 만들지 않는다.
5. 변경 순서·값 복귀·새로고침·다른 초기 디자인으로 재현 검사하고, 분석에 쓰지 않은 설정에서 가격 오차(EUR)를 기록한다.
6. 선반 이후 책상·옷장을 각각 독립 검증한다. 국가 간 단순 환율환산으로 동일 규칙이라 가정하지 않는다.

현재 완료: 1개 구성에서 뒷판 전환/복귀. 나머지 실험과 가격 공식 추정·검증은 미완료.


## R5 구현·검증 업데이트 — 2026-10-14

사용자가 지역별 언어/통화와 동일 가격 로직 구현을 승인했다. 공개 번들 산정 단계는 `pricing-source-audit.md`에 분리하고, 이를 독립 함수 `src/lib/commerce/reference-pricing.ts`로 재구성했다. 실제 단가표 없는 상태에서는 `unavailable`을 반환한다. 합성 단가 11개 검사는 계산 순서 검증이며 Tylko 실제 가격 일치 증거가 아니다.

현재 Tylko 페이지가 노출한 coefficients URL은 `https://tylko.com/api/v1/pricing/coefficients/`. 연결된 Chrome에서 읽기 요청은 HTTP403(Cloudflare)으로 끝났다. 실제 단가·지역 인상률·현재 프로모션 계수를 확보하지 못했다. 인증정보를 저장하지 않았고 접근 차단을 우회하지 않았다. 기존 번들 내 상수만 실제 영업 단가로 대체하지 않았다.

지역 선택은 KR/ko/KRW, US/en/USD, JP/ja/JPY, EU/en/EUR. EU는 10개 배송국가 선택을 제공하나 국가별 세금·배송비 계산/배송 가능성 확정은 아니다. 기존 I18nProvider 쿠키가 단일 지역 상태이며 EU국가만 별도 로컬 저장한다. 상품/컨피규레이터·상품 카드·장바구니에서 통화 표시 연결. canonical 가격은 기존 KRW 계산을 유지한다. 해외 표시는 ECB 2026-10-13 EUR 기준(KRW1500.81, USD1.1188, JPY176.91)의 예상 환산가격으로 명시한다. 환율은 날짜가 있는 스냅샷이며 자동갱신은 미구현. 기존 주문/결제 KRW 의미를 변경하지 않았고 해외는 견적 안내한다.

검증: 독립 산술16검사 통과, 주요 변경 lint 오류0/경고0. Chrome 상품 sideboard-terra에서 너비110→111cm 편집 후 JP→US→EU→KR 전환 시111cm 유지. 같은 구성 표시가격 KRW245600 / USD183.09 / EUR163.64 / JPY28950. EU 독일→프랑스 선택 확인. 모바일390×844 지역선택 메뉴 표시 확인. 사례 markets-001. 장바구니에 실제 테스트 물품을 넣거나 주문·결제하지 않았다.
