# Blum 경첩·보링 구현

## 선택한 제품과 출처

품번 미정 상태에서 사용자가 구현을 승인하여, 현재 인셋 도어에 **CLIP top BLUMOTION 110° INSERTA 71B3790 + 0mm EXPANDO 플레이트 174H7100E**를 선정했다. 구매 확정이나 기존 GLB의 제품 식별을 뜻하지 않는다.

- [Blum 카탈로그 제품표](https://publications.blum.com/2024/catalogue/en/76/): 인셋/INSERTA 품번.
- [Blum 설치 계획](https://publications.blum.com/2024/catalogue/en/77/): 인셋 TB/MD/여유 간격 및 플레이트 후퇴량.
- [Blum 기술자료, p.3](https://d2.blum.com/services/BEC003/clp0001-td-032_td_dok_bau_$sen_$aof_$v4.pdf): 컵과 INSERTA 보링 도면을 이미지로 확인.
- [플레이트 카탈로그](https://publications.blum.com/2024/catalogue/en/152/) 및 [174H7100E 공식 제품 규격](https://shop-ua.blum.com/catalog/clip-montazhni-planky/174h7100edueplv500ni): 지름·깊이·37/32 규격.

| 항목 | 적용값(mm) |
| --- | --- |
| 컵 | Ø35, 깊이13 |
| INSERTA 고정홀 | Ø8, 깊이13, 상하간격45, 컵 중심에서 문 안쪽9.5 |
| 측판 고정홀 | Ø5, 깊이11.5, 상하간격32 |
| 인셋 플레이트 보링열 | 본체 전면에서37 + 문 두께 + 1.5 후퇴 |
| MD0 컵 가장자리 TB | 7 − 실제 경첩측 문틈;3–7 범위 |
| 컵 중심 | 경첩측 문 가장자리에서TB + 17.5 |

컵 상하 중심은 문 끝에서50mm로 정한 **프로젝트 설계값**이다. Blum의 모든 문에 대한 권장값으로 주장하지 않는다. 구현은 두께16–24mm, 폭70mm/높이157mm 이상에 제한한다. 600mm 초과 도어는 무게·경첩 수 검토를 표시한다. 문틈은 공식 R1 표의 보수적 최대값에0.2mm 여유를 더해 검사한다.

## 구현과 사용

- `lib/three/blum/boring.ts`: mm 단위 구멍 위치·가공축·깊이를 계산한다. 실제 측판을 찾아 좌우 방향을 결정한다.
- `geometry.ts`: 원통 불리언 차집합으로 실제 막힌 구멍을 만든다. 16mm 문에는 컵 바닥 뒤3mm가 남는다. 화면의 구멍은 텍스처나 검은 원이 아니다.
- Door의 컵·암은 문짝, 플레이트는 실제 측판 그룹에 귀속된다. 분해 시 경첩/플레이트 쪽 면이 위로 향한다. 조절발은 기존처럼 바닥판에 체결되어 있다.
- **보기 → 보링**: 경첩을 숨기고 문을 열어 타공 확인. **분해 + 보링**으로 문 뒷면의 컵홀과 고정홀을 확인할 수 있다.
- `blum/cnc.ts`는 동일 데이터를 CNC `manufacturingBoring`에 추가한다. 도어는 후면(bottom), 측판은 판재 좌표의 정확한 면에 가공한다. 기존 커넥터 가공을 보존한다. CNC 원점은 실제 모델 치수에서 계산한다(기존 표시 판재 치수는0.1mm 반올림).
- 측판 부재/간격 부적합, 잔여 두께 부족, 공유 측판의 반대편 보링 겹침, 기존 원형 가공과의 충돌을 검출한다. 미확정 조합은 생산 차단 사유를 남긴다. 임의 벽에 보링을 생성하지 않는다.
- 보링 보기에서 숨긴 하드웨어와 열린 문은 USDZ 복제본에서 정상 조립 상태로 복원한다. 실시간 화면은 변경하지 않는다.

## 검증과 한계

- 보링/표시 회귀17개: 실제 메시 레이 교차로13mm 컵 깊이·앞면 잔여 두께·11.5mm 측판 깊이 확인, 좌우 반전, 타공 충돌, 바닥 방향, AR 상태 복원.
- 6스타일 생성기 → 3D 보링 → CNC 좌표/가공면 통합 검사 통과. 당시 Gradient 사례1개 도어는 적합한 측판을 찾지 못해 생산 차단됨; 원본 생성기를 임의 변경하지 않음.
- 변경 ESLint 및 webpack production build 통과.
- 경첩 외형은 컵/플랜지/암/플레이트/고정부를 구성한 **파라메트릭 시각 모델**이다. 공식 STEP/GLB와 기구학 데이터는 확보하지 못했다. 암 길이가 변하는 시각 링크와 도어 가장자리 회전은 실제4절 링크의 정확한 궤적이 아니다. 공식 CAD 외형 동치·체결 간섭 전체 검증·실물 조립 검증을 완료했다고 주장하지 않는다.
- 슬롯 가공과의 전체 충돌, 문 무게에 따른 수량 선정, 장비 공구/공차 검증 및 AR 실기기는 미검증.

### 브라우저 확인

동시 개발의 자동 새로고침을 피하기 위해 `/tmp/befun-blum-check-i2w8i1y4`에 소스 스냅샷을 빌드하고 로컬3019포트에서 확인했다. Grid90cm/4단/깊이32cm/하단 도어2개에서20개 보링 표시, 보링 보기의 문 열림/하드웨어 숨김, 분해된 문 뒷면의 컵홀·고정홀, 측판 플레이트 부착 및 위/입체 시점 전환을 확인했다. 기존 하드웨어 수치 회귀89개와 기존 CNC 통합 검사도 통과했다.
