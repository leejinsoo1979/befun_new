# R8 옷장 최종 표시 규칙·뷰어 교정

2026-10-14 / codex-analysis(리더). **옷장 전체가 Tylko와 동일하다는 완료 보고가 아니다.** 사용자가 지적한 wardrobe-2 내부 서랍과 별도 뷰어를 직접 확인하고 수정한 기록이다.

## 발견 원인과 수정

- 이전 Tone 검증은 engine.getRender의 중간 판재 외곽까지만 검사했다. 실제 최종 renderer가 추가하는 폭 −18mm, 높이 +17mm, 내부/외부 Y 보정과 외부 전면 확장이 빠져 있었다. `tone-drawers.ts`에서 최종 표시 패널을 계산한다. 기존 중간 fixture는 보존했다.
- 모든 서랍을 동일 거리로 꺼내던 것을 같은 열의 위→아래 순위/N × 깊이 ×0.95 인출로 수정했다. 이 값은 **화면상의 전시 동작**이며 실제 레일 스트로크/제조 치수 인증이 아니다.
- 옷장 외형 모드는 문을 부분 개방하고 서랍을 닫는다. 내부 구성 선택 시 문·서랍을 열고 정면으로 맞춘다. 보기 메뉴에서 전체 닫기/열기 가능. 개별 hover 동작 전체 일치는 아직 미검증이다.
- 옷장·책상의 별도 알약 버튼 줄을 선반과 같은 CSS의 ‘보기’ 메뉴로 교체했다. 전체 화면은 좌측 하단. Escape는 메뉴로 초점을 돌려주며 상단 사이트 메뉴로 전파하지 않는다.
- `fitView`, `Background`, `Effects`를 선반과 공유한다. VSM 부드러운 그림자, 환경광, 톤매핑도 같은 설정으로 맞췄다. 이전 단일 바닥 평면 제거.
- 고정 최소 줌30cm 대신 가구 너비/깊이 기준으로 카메라가 몸체 안쪽으로 들어가는 것을 제한하고, 보기 메뉴에 확대/축소 추가. 큰 가구도 최대 축소 범위 확보. 모바일 변경과 시점 초기화는 다시 화면에 맞춘다.
- Native fullscreen이 브라우저에서 거부되면 오류 대신 같은 창의 전체 화면으로 전환한다. 종료/Escape 시 스크롤 잠금 복원.
- 하단 상세페이지/카탈로그 연결은 다른 작업자의 구현을 보존했다. 저장·공유·가격·관리자 정책은 변경하지 않았다.

## 남은 차이 (완료 아님)

- Tylko와 카메라 투영·구도, 광원·색상, 실루엣 명도 및 그림자 픽셀 일치. 현재 목표 중 **Befun 뷰어 간 일관성**을 먼저 수정한 상태다.
- 원본의 선택 구획 강조·hover 시 문/서랍 미리보기와 카메라 포커스 전체 전이.
- 원본 옵션 패널의 구획 너비 선택 UI, 가격 영역 등 제품별 전체 UI 동치.
- 실제 레일/힌지 제조 치수 및 모든 조합의 물리적 간섭. 수치 렌더 검증은 제조 검증을 대체하지 않는다.
- 모든 옷장 카테고리·모든 설정의 브라우저 검증은 수행하지 않았다. 본 기록의 사례만 확인했다.

최종 사용자 화면: `user-wardrobe-95-corrected.png` — 폭95/높이276/깊이63, 그래파이트/미스티블루, 구성4, 정면. 기존 localhost3003 탭을 이 상태로 돌려놓았다. 테스트용3318 서버/탭은 종료했고 브라우저 viewport는 원래 크기로 복구했다.
