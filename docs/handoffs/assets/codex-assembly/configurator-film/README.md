# 컨피규레이터 조립·분해 연출 / 왼쪽5 / 2026-10-15

사용자 요청: 조립·분해를 시네마틱하게, 분해 때 생기는 매트 제거, 분해된 판재에 정돈된 라벨 스티커 추가.

- 불투명 베이지 평면과 격자를 제거했다. 투명 shadowMaterial만 접지 그림자를 받는다.
- 분해도 조립과 같은 개별 부품 간격을 사용한다. 기존 0.22초 중첩으로 여러 판재가 동시에 날아가던 연출 대신 역순의 개별 부품 분리/운반을 보여 준다. 카메라 고정을 선택한 기존 빠른 정렬 경로는 보존했다.
- 조립: 펼쳐진 부품 도입 → 실제 이동하는 판재를 따라가기 → 3.2초 완성 오빗. 분해: 가구 전체 도입 → 분리/운반 부품 추적 → 2.4초 펼쳐진 부품 전체 구도. 마지막 구도는 일반 입체 프리셋으로 되돌아가지 않는다.
- 작은 판재는 가까이, 긴 판재는 전체가 들어오도록 실제 회전한 크기로 카메라 거리를 계산한다. 후면판은 뒤쪽에서 보여 준다. 카메라/판재 일시정지 동기화와 수동 드래그/보기/투영 전환은 보존했다. 다음 재생은 시네마틱 perspective로 시작하며 reduced-motion을 존중한다.
- 라벨: 흰색 둥근 종이, 짙은 P01 번호와 판재 종류, 작은 BEFUN 표기/녹색 점. 실제 판재 넓은 면에 부착하고 판재와 함께 이동·회전한다. 분리 후 보이고 조립 접합부에 돌아오면 숨긴다. 수평판·양쪽 방향 세로판·후면판의 단면 대신 넓은 윗면에 배치되는 것을 검사했다.
- 라벨 번호는 기존 화면 panel-index에서 파생한 식별자이다. 제조 라벨/공식 하드웨어 코드가 아니다. AR clone에서 제거되며 설계 저장/공유/주문/CNC에는 추가하지 않는다. 라벨 texture는 unmount 때 dispose하고 geometry/material은 기존 R3F 소유 생명주기를 따른다.
- 조립 완료 hero에서 인물 배경이 갑자기 복귀해 머리가 잘리는 현상을 재현했다. Scene studio 조건 2줄만 수정해 재생 결과가 열린 동안 배경 복귀를 보류하고 닫기/초기화 후 복원한다. 소품/재질/광원은 보존한다.
