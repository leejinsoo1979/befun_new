## 변경

- `/assembly-guide/cabinet`의 보강 패널/백패널을 동일한 **아래 고정 다보 삽입 → 상단 스프링 다보 눌림 → 하단을 받침점으로 상단 세움 → 스프링 다보 복귀·잠금**으로 수정했다. 상단 다보의 수용판이 먼저 있어야 하므로 상판을 후면 부품보다 먼저 조립한다. 공통 생성기/판재 ID/치수/접합 좌표는 보존한다.
- 기존 `BackPanelScene`의 설명용 `SpringPin`을 `SpringDowel`로 추출해 공유한다. 기존 백패널 7단계의 형상·기본 색·동작·핀 참조·스프링 압축 갱신을 보존한다. OVVO PH/PC, Tylko 클립, 다리 기구를 다보에 혼용하지 않는다.
- 후면 부품의 고정 다보와 스프링 다보, 상·하판 수용 구멍을 함께 표시한다. 구멍은 시연 메시에서만 CSG로 파며 MDF 절삭면을 사용한다. `part.panel.manufacturingBoring`, 공통 CNC/타공·주문·저장은 수정하지 않는다.
- `전체 영상 재생` 한 번으로 도어 포함8부품을 끝까지 보여준다. 기본 전체52.2초, 1.5× 약35초. 중간 확인 gate가 없으며 직접 조립의 gate는 보존한다. 전체 영상 탐색·정지/재생·단계 탐색·재시작·자동 시점/수동 관찰을 제공한다.
- 카메라: 펼쳐진 부품 → 선택 부품 → 하우징/커넥터 가까이 → 운반 추적 → 접합 확대 → 후면 하단 다보 → 상단 눌림/세움/복귀 → 부분 완성 모습 → 다음 부품 → 완성 회전/도어 열림. 각 phase의 경계를 연속 보간하며 무작위 흔들림/롤을 추가하지 않는다. 잠금 시점은 상판/현재 후면 부품을 국소 투명 관찰로 보여준다.
- 카메라·핀·판재/도어는 재생 위치에서 절대 샘플링한다. 일시정지/뒤로 탐색에서 직전 프레임의 진행이 남지 않는다. 동작 줄이기 설정은 큰 카메라 이동을 줄인다. 영상 중 드래그 관찰은 재생을 정지한다.

## 근거와 확인하지 않은 값

- 방식: 사용자 직접 지시와 기존 [공식 백패널·보강 안내](https://tylko.elevio.help/en/articles/32-back-panels-and-supports), `backPanel.ts`의 확인된 순서. 이번 지시로 이전 인계의 ‘후면 위치 연습만 구현’을 실제 시연에서 교정했다.
- 핀 외형·5mm 연장·7mm 수용 구멍·10mm 설명용 구멍 깊이는 기존 백패널 예제값이다. 핀 간격은 실제 후면 부품 폭에 예제 비율로 배치한 **설명용 위치**이고 공급사 가공 도면이 아니다. 12° 기울임·운반 경로·52.2초·FOV/카메라 이동은 연출 값이다.
- 다보 실물 CAD/제조 치수/스프링 강성/탄성/공구/필요 힘·실제 공급사 완제품 조립 순서·전체 물리 충돌 승인 미확인. `manufacturingApproved=false`. 전체 영상은 실시간3D이며 MP4 파일을 내보낸 것은 아니다. 실제 사용자 주문/책상/옷장 연결은 이전 인계의 리더 공통 입력 계약 요청과 별개다.
