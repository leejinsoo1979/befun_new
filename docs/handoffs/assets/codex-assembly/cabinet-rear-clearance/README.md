# 백패널·후면 보강 패널 관통 수정

왼쪽5 / 2026-10-14. 기존 작업·세션 유지, 사용자 직접 지적에 대한 수정.

## 재현과 수정

기존 앞쪽 바닥→좌석 직선 carry는 progress 약0.4에서 상판과 실제로 겹쳤다. before-support.jpg 및 OBB 충돌 회귀 사례로 재현했다. 캐비넷 원본 부품 ID/치수/조립 순서는 유지한다.

두 후면 부품을 처음부터 본체 뒤쪽 바닥에 배치한다. 순서: 바닥에서 먼저 들어 올림→본체 밖에서 기울임→상판 아래 높이까지 내림→뒤쪽 개구부 접근→하단 고정 다보 진입→상단 스프링 다보 누름→아래쪽 뒤 모서리를 받침점으로 세움→스프링 복귀/잠금. carry·접합부 카메라도 뒤쪽에서 따라간다. 직접 조립과 전체 영상은 같은 absolute pose를 소비한다.

OVVO 접합부 안내에서 백패널 탭으로 진입하는 기존 단독 백패널 7단계도 뒤쪽 접근/모서리 받침점으로 교정했다. 기존 7단계와 하단 고정/상단 스프링 역할을 보존한다. [사용자 제공 공식 출처](https://tylko.elevio.help/en/articles/32-back-panels-and-supports)의 절차 구분을 유지하며, 이번 경로/각도/핀·홀 치수는 설명용이다.

## 유한 두께의 회전 여유

공유 부품의 rear 높이는 개구부 높이와 정확히 같고 생산 여유 계약이 없다. 두께를 가진 판재를 회전시키면 마지막 작은 각도에서 꼭짓점 높이가 개구부보다 커진다. 안내 전용 상단 회전 여유 **0.6mm**를 CabinetPanel/BackPanelScene 내부 렌더에 적용했다. 하단은 그대로 유지하고 상단 핀 기점과 카메라 표적도 같은 만큼 따라간다. 이 값은 제조사 공차/실측값이 아니다. 공통 생성기, source box/주문 치수, CNC/하드웨어 원본은 수정하지 않았다. 제조 데이터가 제공되면 실제 여유와 타공으로 교체해야 한다.
