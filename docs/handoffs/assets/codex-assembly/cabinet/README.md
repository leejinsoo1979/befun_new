# BEFUN-CABINET-PRACTICE-READY

왼쪽5 codex-assembly, 기존 세션 `01a13548-3202-7aa2-8a54-0ff6840d3f75`. 사용자 요청: 접합부 예제를 넘어 실제 Befun 캐비넷 한 대를 화면에서 모의 조립하기.

## 실행과 동작

- `/assembly-guide/cabinet`: 110 × 약43 ×32cm, Terracotta 1단 도어 캐비넷. `완성 모습`, `직접 조립`, `자동 조립` 제공. 기존 접합부 안내 헤더의 `캐비넷 조립`에서 진입한다.
- 공통 `buildBefunShelfModel` → `toCncPanels` → 기존 `createAssemblyPlan`을 소비한다. 판재·도어 8개, 안정 CNC ID `befun_p0...p7`, 몸통 접합6개/커넥터12개. 새 가구 생성기·저장 형식·주문 상태는 만들지 않는다.
- 직접 조립: 부품 선택 → 하우징/커넥터 준비 → 표시된 위치에 놓기/끼우기 → 체결 확인. 잘못된 부품은 안내만 하고 다음 단계로 넘어가지 않는다. 후면 부품은 위치 연습, 도어는 공통 경첩 위치를 소비한다.
- 전체·부품·접합부·내부 보기, 일시정지·동작 탐색·속도·단계 초기화, 완성 후 도어 열기. 준비 완료 후 전체 화면으로 돌아와 배치 위치를 보여준다.
- 양면 Terracotta 라미네이트, 외부 자작 적층 엣지, 내부 가공 면 MDF. 실제 공통 가공 메시를 cm→mm로 한 번 변환한다. PH/PC는 공유 하드웨어 모델과 계약을 그대로 소비한다.

## 근거와 범위

- 첫 2단 구성의 18mm 중간판은 양쪽 12.5mm OVVO 홈 교차 경고6개가 발생했다. 이를 제조 가능하다고 표시하지 않고, 공통 접합 검사를 통과하는 1단 구성을 사용했다. 이 구성은 특정 카탈로그 SKU를 동일하게 복제했다는 주장이 아니다.
- 몸통은 V-1230P 영구형이다. 초기화/이전 단계는 화면 연습이며 실제 분해 안내가 아니다. R 해제15mm·Tylko 클립·다리·백패널 원본 안내는 기존 경로에서 분리하여 유지한다.
- 후면 보강대/백패널의 별도 정밀 체결 기구는 재현하지 않았다. 공통 생성 결과의 실제 위치를 맞추는 연습이다. 경첩은 기존 공통 시연 모델이며 공급사 CAD가 아니다. 발은 기존 고정된 25mm/10mm 외형을 사용하며 다리 정밀 조립 완료를 뜻하지 않는다.
- 하우징 준비의 24mm/30mm 접근, 부품 운반 경로·속도는 화면 연출 값이다. 공급사 언더컷·탄성·실물 충돌·제조 승인·실제 출고 조립 순서는 확인하지 않았고 `manufacturingApproved=false`를 유지한다.
- 현재 한 구성만 제공한다. 모든 사용자 주문 디자인 연결과 책상/옷장 진입 버튼은 리더의 공통 입력 계약 연결이 필요하다. 이 경로는 실제 생성 결과/ID/치수/접합 정보를 소비하지만 상품 선택 상태를 전달받지는 않는다.
