# Tylko 조립 자료 통합 / R7

2026-10-14 · 리더. 구현 범위는 제공 ZIP의 설명서 열람과 접합 원리 시뮬레이션이다. 실제 주문 가구의 부품별 조립 순서 생성이나 제조 규격 확정까지 완료했다는 뜻은 아니다.

## 진입과 관리자 선택

- `/optimizer` 상단 **패널 접합 방식**: OVVO / Tylko 클립. 기존 관리자 권한 검사 유지.
- 선택값은 기존 `befun-optimizer-connectors` localStorage에 저장한다. **현재 브라우저 작업 설정**이며 사이트 전체 또는 주문별 서버 설정이 아니다. 그 저장 범위는 사용자에게 질의했으며 답변 전 임의 DB 정책을 추가하지 않았다.
- 선택기 옆 **시뮬레이션·조립 안내**는 현재 방식의 안내로 연결한다.
- `/assembly-guide`는 저장된 방식을 읽는다. 명시적 `?system=ovvo` 또는 `?system=tylko-clip` 링크는 해당 안내를 열기만 하며 관리자 설정을 변경하지 않는다.
- 구형 OVVO 저장값(시스템 필드 없음)을 호환하고, 손상 JSON/알 수 없는 시스템/잘못된 공구번호를 걸러낸다. 다른 탭에서의 저장 변경도 구독한다.
- `topic=connector`는 기존 OVVO, `topic=legs`·`topic=back-panel`은 새 Tylko 부속 안내로 연결한다. `chapter=legs` 등 직접 진입도 지원한다.
- OVVO 안내의 세부 모델 선택은 기존 화면 기능을 사용한다. 관리자 몸통 모델을 안내의 모델 선택에 자동 전달하는 기능은 이번 범위에 포함하지 않았다.

## 자료와 출처

`import.json`에 ZIP SHA256, 파일별 SHA256·바이트 수를 기록했다. 원본은 `public/assembly/tylko/`, 인덱스는 `src/lib/assembly-guide/tylko-manual/assets.json`이다. 서비스 코드에 사용자 PC 절대 경로를 넣지 않았다.

- PDF 14개: 제품 예시 53쪽, 낮은 가구 29쪽, 높은 가구 32쪽, 부속 웹 가이드 10개, KNAPP 참고 도면 1개.
- 영상 18개 및 포스터 18개, 도해 79개, 원문 가이드 10개. 전체 144개 의미 있는 원본 파일.
- 전체 파일 해시 일치, 18개 영상 전체 디코딩 성공. 영상별 결과 `video-decode.json`.
- 파일명의 깨진 물음표와 원본 목록명의 차이는 영상 ID로 정확하게 연결했다. 파일 정렬 순서를 이용해 매칭하지 않았다.
- 모든 PDF·영상·도해를 자료실에서 열 수 있다. 영상은 선택한 것만 마운트하며 preload=none, 도해는 lazy loading.

## 확인된 조립 원리

- 가로/세로판: 같은 색 핀·클립을 맞추고 접합면 방향으로 진입한 뒤 장축 방향으로 체결. 검정/은색, 구형 검정/주황. 색상별 잠금 역할은 확인되지 않았다.
- 클립 방향 교정: 보호판으로 받치고 상대 판을 눌러 분리한 뒤 레일·힌지를 전면으로 돌려 재결합.
- 백패널 W·보강대 S: 하단 고정핀부터 넣고 상단 스프링핀을 눌러 체결. 분해는 테이프 지지와 행 접합 해제 순서를 따름.
- 240cm 초과 폭의 모듈 연결: 가로/세로판 클립과 다른 암·수 연결부·다월. 제공 영상에서 가로판당 2개, 깊이 24cm에서는 1개. 분해 설명서의 4mm 육각렌치·반시계 두 바퀴는 해당 연결부 절차이다.
- 인서트: 8자 연결부 작은 원의 방향 확인. 제품 구조에 따라 위/아래 장착, 분리할 때 위·앞쪽 이동.
- 서랍: 박스 구성 순서와 뒤판/옆판/바닥 분리; 레일 장착; 양쪽 노란 캐치 해제; 회색 높이 조절부.
- 도어: 힌지 스냅 체결·양 끝 해제·3축 조정·범퍼. Blum/Häfele 도해 차이는 원문에서 확인.
- 다리: 나사 3개와 중앙 은색 핀은 바닥판에 남는다. 키홀 장착판과 다리를 함께 밀어 체결; 핀을 누른 채 역방향으로 밀고 분리한다. 3D에 3개 키홀·인접 2개 접힌 가장자리·중앙 핀 표현.
- 플린스: 분해 시 짧은 부품 풀기→긴 부품→짧은 부품 회전/분리. 조립 영상은 가로지르는 부품→짧은 부품→가장 긴 부품 순서.
- 낮은/높은 가구 분리, 세우기, 벽 고정, 운반 보호, 스티커 제거도 각각 설명한다. 큰 가구 세우기 영상은 뒤 1명+앞 최소 2명, 더 큰 가구에는 4명을 권장한다. 특정 166766 예시의 2인 그림을 모든 가구에 일반화하지 않았다.

## 화면 기능

17개 항목, 3D/원본 도해/영상 전환, 재생·정지·속도·타임라인·앞뒤 단계·현재 동작 끝 보기, 확대/회전/내부 보기/시점 초기화, 단계별 확인 체크. 확인 체크는 이전 단계와 동작 끝 확인을 요구하고 탐색은 자유롭다. 체크는 실제 조립 품질을 판정하는 센서가 아니다.

3D는 부속별 **설명용 대표 구조**다. 실제 구매 가구의 모든 판·나사·레일·핀 수량과 숨겨진 내부 형상을 정확히 복제한 모델이 아니다. 원본 PDF/영상이 함께 제공된다.

## 미확인·후속 작업

1. Tylko 실물 부품의 정확한 품번·홈·나사 간격·잠금형 내부 형상·허용오차·강도. 기존 설명용 32×9/깊이12/이동11 등은 측정치가 아니다.
2. `connector.pdf`는 KNAPP Mod-eez 자료다. 32.00은 나사 중심 간격이며 클립 전체 길이가 아니다. Tylko 공급품 동일성은 확인되지 않았으므로 Tylko CNC에 전용하지 않는다.
3. 실제 주문 설계에 따라 부품 ID·수량·위치를 연결하는 전체 가구 조립 시뮬레이션. 현재는 대표 구조다.
4. 관리자 선택의 상품·주문별 또는 사이트 전체 서버 영구 저장 범위.
5. 제조 가공 승인. Tylko 선택 시 기존 미확정 CNC 차단을 유지한다. OVVO 선택으로 복귀할 때 기존 OVVO 처리만 복구한다.
6. 플린스·레일·힌지·연결 캠의 세부 기구는 도식이며 완전한 실물 CAD가 아니다. 정확한 치수를 추측해 메우지 않는다.
