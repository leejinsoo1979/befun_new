# 블룸형 보기 모드

## 조사와 구현 범위

2026-10-13, 실제 [Blum 캐비닛 구성기](https://e-services.blum.com/main/#/PAI010) V4.0.18.1에서 확인:
- 주황색 면으로 방향을 나타내는 큐브: 정면/후면/좌측/우측/위/아래 및 표준 보기.
- 투시도↔등각투상 전환과 쪼개진 보기(판재 분해).
- 설정의 목재 부품 치수 표시, 어두운 색상 모드.

반투명/와이어프레임은 해당 블룸 화면에서 별도 메뉴를 확인하지 못했지만 사용자의 명시적 추가 요청으로 구현했다. 블룸의 전체 기능·픽셀 동치를 주장하지 않는다.

## 사용

컨피규레이터 캔버스 왼쪽 위 도구 모음. 모바일은 `보기` 버튼으로 펼친다.

- 시점: 정면, 후면, 좌측, 우측, 위, 아래, 입체.
- 투영: 투시도와 평행 투영을 각각 별도 버튼으로 제공한다.
- 표시: 실사, 반투명(원색 + 투명 면 + 윤곽선), 와이어프레임(삼각분할 대각선을 제거한 모서리 선).
- 분해: 부품이 순차적으로 이동·회전하여 바닥에 겹치지 않게 정렬된다. 조립을 누르면 조절발이 미리 체결된 하단 가로판 → 해당 단 세로판 → 다음 가로판 순서로 쌓이고, 뒷판·문·서랍이 이어진다.
- 조립 영상: 일시정지/재개, 0.5×·1×·2× 속도, 건너뛰기, 완료 후 다시 보기를 제공한다. 현재 단계와 진행률을 표시하고 카메라가 펼쳐진 부품까지 부드럽게 맞춘다. 치수 등 구조 옵션 변경 시 조립 상태로 초기화한다.
- 문·서랍은 조립된 부품 단위로 이동한다. 나사·힌지 체결이나 물리적 충돌을 검증하는 제조용 조립 지침은 아니다.
- 치수: 조립 상태에서 표시. 분해도에서는 부정확한 치수와 행 편집 충돌을 막기 위해 숨긴다.
- Space 또는 기존 정면 버튼으로 정면 복귀. 입력창과 버튼의 키보드 조작은 가로채지 않는다.
- 후면/하부/기술 표시/자유 회전에서는 룸을 숨겨 벽이나 바닥에 모델이 가리지 않게 한다.

## 통합

`src/components/three/display/`에 상태, 도구 모음, 카메라, 표시 재질, 조립 계획·타임라인·바닥·재생 패널과 AR 복원 유틸리티가 있다. Scene은 카메라와 화면 연결부, Shelf는 조립 계획·부품 그룹·콜라이더 조건을 연결한다. 기존 조명·재질 생성·스타일 계산·가격·저장 데이터는 유지한다.

표시 상태는 설계 저장에 포함하지 않는다. WebXR의 Shelf는 기본 조립 상태로 렌더한다. USDZ는 복제본에서 표시 오프셋과 임시 재질을 복구하여 원본 조립 모델을 내보낸다. 임시 재질과 EdgesGeometry는 모드 전환/객체 제거 시 해제한다.

## 검증

- `node --experimental-strip-types --test src/components/three/display/*.test.mjs`: 9개 통과. 카메라 맞춤, 조절발의 바닥판 소속과 바닥 간섭 방지, 단별 조립 순서와 시간, 이동 경로 연속성·끝점, 보강판 눕히기, 100개 부품의 결정적 바닥 배치와 비중첩, AR 좌표·회전·재질 복원 및 원본 불변 검사.
- 변경 파일 ESLint: 오류/경고 없음. 전체 lint: 오류 0, 기존 경고 13개.
- 프로덕션 `npm run build`: 성공 (추가 표시 모드 포함).
- 실제 Chrome: 정면, 후면, 위 평행투영, 입체 분해도, 반투명, 와이어프레임, 실사 복원, 반투명+분해도 시각 확인. 390×844 모바일 메뉴 펼침/접힘 및 모델 화면 맞춤 확인.
- 조립 시뮬레이션: 바닥 정렬 → 단별 조립 → 완료, 일시정지, 2× 재생, 다시 보기의 자동 분해·재조립, 깊이 변경 시 초기화를 실제 Chrome에서 확인. 모바일390×844 재생 패널 확인. 추가 구현 후 변경 ESLint 및 production build 재통과.
- AR 실기기 실행 및 블룸과 동일한 시각 결과는 미검증. AR 복제본 변환은 단위 테스트로 확인.

## 시네마틱 조립

- 재생 패널의 `시네마틱`으로 자동 카메라를 켜고 끈다(기본 켜짐). 시작 시 투시도로 전환한다. 시스템의 동작 줄이기 설정에서는 기본 꺼짐.
- 넓은 도입 장면 → 조립 중인 단을 따라가는 낮은 시점 → 완성된 가구를 보여주는3.2초 오빗. 각 부품은 별도 시간 슬롯으로 움직이고 슬롯 사이에는0.12초 여유를 둔다. 부품 배치 순서와 실제 위치는 동일하다.
- 일시정지는 부품과 카메라 모두 정지한다. 카메라를 직접 드래그하거나 재생 중 보기 버튼을 누르면 수동 보기로 인계한다. 다시 시네마틱을 켜면 자동 추적이 재개된다.
- 레터박스는 클릭을 막지 않는 화면 장식이다. 조명·재질·가구 설계·AR 데이터는 변경하지 않는다. 완성 후 마지막 구도를 유지한다.
- `cinematic.test.mjs`: 경로 연속성/정지 결정성, 단 사이 정지 시간, 세로·가로 화면과40/240/450cm 너비의 완성 구도 화면 맞춤 검사.
- 시네마틱 추가 후 표시 테스트15개, 변경 ESLint, TypeScript, 독립 스냅샷 production build 통과. Chrome에서90cm/4단의 분해→조립 추적→일시정지/재개→완성 오빗→100% 완료를 확인했다. 세로 화면 완성 구도는 투영 수치로 검증했다.

### 순차 체결 연출 개선
- 렌더 배열 순서와 무관하게 바닥판→왼쪽부터 세로판 하나씩→같은 단 후면 보강대/뒷판→다음 가로판 순으로 진행한다. 도어·서랍은 몸체 이후 설치한다. 조절발은 바닥판 소속을 유지한다.
- 상승과 운반을 하나의 곡선으로 연결하고 회전을 미리 마친 뒤 마지막8cm를 감속 체결한다. 실제 커넥터 변형·작업자의 손 동작을 계산하는 물리 시뮬레이션은 아니다.
- 세로판의 체결 위치를 좌우로 추적하고 가로판에서는 높은 시점, 후면 보강대에서는 뒤쪽 측면으로 이동한다. 완성 구도와 수동 인계는 유지한다.
