# 반응형 선반 소품

## 사용

뷰어의 책·화병 아이콘 **소품**으로 전체를 표시/숨긴다. 기본은 표시한다. 가구 너비·높이·깊이·밀도·스타일을 바꾸면 실제 판재 공간을 다시 계산한다. 소품은 화면 장식이며 가격, 저장 디자인, CNC에는 포함되지 않는다.

## 모델과 배치

- 자체 제작 3D 소품: 제목·책등·커버·종이 단면이 있는 책, 눕힌 책 묶음, 입구와 내부가 있는 도자기 화병, 뚜껑/라벨/직물 질감 수납상자, 흙·곡선 줄기·곡면 잎이 있는 화분.
- 원본 Tylko 모델을 가져온 것은 아니며, 동일 자산/픽셀 수준 일치를 주장하지 않는다. 사용자 제공 화면의 소품 연출을 참고한 독립 모델이다.
- 판재를 같은 높이에서 연결하고 칸막이·상판·후면 보강대의 실제 좌표를 반영한다. 문/서랍과 겹치는 칸에는 배치하지 않는다. 열린 문도 수납 공간으로 취급하여 비운다.
- 물건 자체를 늘이거나 줄이지 않는다. 낮은 칸에는 낮은 책/화병/눕힌 책을 선택하고, 좁은 칸에는 책 수를 줄인다. 여유가 없으면 비운다. 빈 공간을 남기고 최대14개 묶음을 전체 높이에 분산한다.
- 조립·분해·보링·반투명·와이어프레임에서는 자동으로 숨기며, 실사 조립 상태로 돌아오면 사용자 토글 상태를 복원한다. AR 복제본에서는 소품을 제거한다.

## 성능과 검증

재질별 지오메트리 병합으로 드로콜을 줄인다. 책98권 시험에서12개 이하 메시로 묶인다. 책등 텍스처와 재질은 크기 변경 동안 재사용한다. 소품 메시의 raycast를 비워 행 선택을 막지 않는다. 제거 시 소품 지오메트리/재질/텍스처를 해제한다.

- `node --experimental-strip-types --test src/components/three/decor/*.test.mjs src/components/three/display/*.test.mjs`: 소품8개 + 기존 표시17개 통과. 치수별 안착/간섭, 크기 불변, 문/서랍 제외, AR 제거, 실제 모델 외곽과 배치 예약 공간 일치, 배치 병합 검사.
- `node scripts/decor-integration.test.mjs`: 6개 스타일 × 너비/밀도/행높이/제품군432개 설정, 소품3,074건의 판재 비간섭 확인.
- 변경 ESLint 통과. 공유 개발 생성타입에서 `LayoutRoutes` 오류가 있어 별도 스냅샷의 production build로 전체 TypeScript와 빌드를 검증했다.

- Chrome에서 소품 토글, 너비30/90/232cm, Grid→Slant 변경, 하단 행 도어Max 추가 시 해당 칸 소품 제외를 확인했다. 소품은 행 선택 클릭을 가로막지 않는다.

## 표면 품질 개선

사용자 피드백에 따라 직물의 직조 요철, 종이 적층 요철, 도자기의 미세 기공과 거칠기 변화를 추가했다. 밝은 유약 도자기와 어두운 무광 도자기를 다른 반사 설정으로 만들고 잎에는 색 변화와 잎맥을 넣었다. 소품별 환경 반사 강도를0.45~0.82로 조정했다. 전체 Scene의 노출/조명과 Effects는 그래픽 담당 소유를 유지한다. 재질 개선이 원본 Tylko와의 시각 동치를 의미하지 않는다.

데이터 맵은 선형 색공간, 색 맵은sRGB로 구분하고 밉맵과 이방성 필터링을 사용한다. 장면 안에서 공유하고 소품 해제 시 함께 dispose한다.
