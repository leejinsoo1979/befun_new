# 03 — Claude 3D 하드웨어 담당 (기존 역할 코드 Claude-2)

작업 ID R1-VISUAL. 결과는 [하드웨어 인계](../../handoffs/claude-2-hardware.md)에 기록합니다.

## 허용 파일

신규 `src/components/three/furniture-hardware/**`, 해당 디렉터리의 부품 preview/검증, 본인 인계 문서. 기존 `LevelingFeet.tsx`, `reference-feet.ts`, `hardware.ts`, `reference-hardware.ts`, `Shelf.tsx`, 재질/Scene/Effects는 읽기 전용입니다. 기존 자료를 재사용할 필요가 있으면 리더에게 연결 요청을 남깁니다.

## 지금 가능한 일

1. 기존 조절발·문·서랍·손잡이의 메시, 크기 단위, 재질 생성/해제, 배치 의존성을 조사합니다.
2. 부품별 재사용 가능/수정 필요/근거 부족을 분리하고 필요한 치수 목록을 기록합니다.
3. 공통 계약에 맞춰 외부 치수·앵커·회전·재질을 입력받는 순수 표시 컴포넌트 경계를 만듭니다.
4. 리더의 확정 사양이 있는 부품부터 형상을 구현합니다. 없는 사양을 임의 치수로 채워 Tylko와 동일하다고 하지 않습니다. 개발용 임시 형상은 preview 밖에 노출하지 않습니다.

## 일관성 기준

- 개수·좌표·어느 판재를 지지하는지는 리더가 정합니다. 전체 폭을 보고 이 컴포넌트에서 발 간격을 다시 계산하지 않습니다.
- 공통 hardware 앵커는 상부 체결 기준점입니다. 메시 중심을 앵커로 오인하지 않도록 bounds를 기록합니다.
- 신규 계약은mm, 기존 장면은cm 경계가 있으므로 리더 어댑터를 사용합니다. 기존 부품을 옮길 때 높이가10배 달라지는 일을 방지합니다.
- 재질은 주입받습니다. 단색 노이즈/roughness/envMapIntensity를 부품 내부에서 일괄 덮어쓰지 않습니다. 소유하지 않은 공유 texture/material을 dispose하지 않습니다.
- 발 종류, 높은 다리, plinth, 벽걸이는 다른 구조입니다. 벽걸이에 발을 자동 추가하지 않습니다. 숨겨진 체결부의 정확도를 외형만으로 확정하지 않습니다.
- 손잡이·힌지·레일·옷봉 등 확대는 확정 사양과 독립 컴포넌트부터 진행합니다. 문·서랍의 위치/개폐 규칙은 리더 소유입니다.

## 산출물과 완료 기준

부품 목록/사양 부족 표, 구현 컴포넌트, 각 부품의 로컬축·앵커·bounds·재질 소유권, 정면/측면/하부 비교와 변경 파일을 인계합니다. 같은 카메라·단위에서 비교하고 구조 치수와 시각 품질을 분리합니다. 알려진 치수 일치, 앵커 접촉, 회전, 자원 재사용/해제 검증이 필요합니다. 장면 전체 광원 수정이 필요하면 기존 그래픽 담당에게 근거와 제안만 남깁니다.

## 화면 위치 및 기존 그래픽 역할 병행

사용자 첨부 화면의 **왼쪽 첫 번째 Claude(기존 claude-graphics)**에게 배정합니다. 새 하드웨어에는 위 파일 경계를 적용합니다. 기존 본인 소유 materials.ts 작업은 병행할 수 있으므로 위 재질 읽기 전용 규칙에서 해당 기존 담당 파일만 예외입니다. 환경광 변경 금지 등 기존 사용자 제약은 유지합니다. Scene/Effects·카메라·커서 줌은 이 배정으로 수정 권한을 확대하지 않습니다. 진행 중인 그래픽 이슈와 기존 잠금 목록을 인계 문서에 기록하고, 타 담당 잠금과 충돌하면 변경안을 리더에게 넘깁니다. 하드웨어 재질 주입과 공유 자원 소유권 규칙은 동일합니다.
