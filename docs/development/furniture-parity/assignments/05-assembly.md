# 추가 왼쪽5 · Codex 조립 — OVVO 형상·맞물림 실제 교정 / R2.1-ASM

## 이번 작업의 결과

`/assembly-guide`의 OVVO 화면을 공식 자료와 교정된 공유 부품으로 다시 연결한다. 기존 Tylko 5단계 시연은 유지한다. 사용자는 현재 OVVO 모양이 틀렸다고 지적했으므로, ‘설명용’ 문구 추가만으로 완료 보고하지 않는다.

소유: `src/components/assembly-guide/**`, `src/lib/assembly-guide/**`, `src/app/assembly-guide/**`, `docs/assembly-guide.md`, 신규 `docs/handoffs/assets/codex-assembly/r2/**`. HW의 `furniture-hardware/ovvo/**`는 읽기 전용이다.

## 실행 순서

### A. HW 인계 전 즉시 수행

1. 현재 P/R 화면의 정면·측면·착좌 단면과 R 삽입→슬라이드 중간을 캡처한다. OVVO-AUDIT-001/002/003과 연결한다.
2. P=PH/PC/PH, R=PH/RC/RH의 상대 부품·움직이는 판·고정 판을 공식 설치도에 주석으로 표시한다. 기존 releaseTravel15가 해제 도면 표기라는 사실과 현재 조립에 사용된 위치를 대조한다. 반대 방향 애니메이션이면 무조건 맞는 해체법이라고 가정하지 않는다.
3. GuideScene 내부의 형상 생성과 pose 변환을 분리할 패치를 준비한다. 새 부품 치수/외형을 독자 제작하지 않는다. 카메라/진행률/모델 전환 상태 처리는 먼저 정리할 수 있다.

### B. HW-CONTRACT-READY 이후

4. HW의 실제 import와 기준점 계약을 읽고 PH/RH/PC/RC를 연결한다. 기존 Housing/Connector의 임의 구현이 실행 경로에 남지 않게 한다.
5. 예제 접합점을 HW 앵커로 변환한다. mm 장면이므로 추가 0.1 스케일을 넣지 않는다. 가구 cm 장면과 이 시연 mm 장면을 혼동하지 않는다.
6. 포켓과 부품의 착좌 단면을 비교한다. 실제 언더컷 단면이 불확실하면 그 영역의 표현/판정을 분리하며, 잘못된 직선 포켓과 충돌하는 부품을 투명도로 숨기지 않는다. 정확한 가공 단면으로 소개하지 않는다.
7. P는 압입, R은 도면에서 확인한 삽입·슬라이드로 구별한다. 각 단계는 `jointPose(model, step, progress)` 같은 **절대 샘플 함수**에서 결정하고 프레임 누적으로 움직이지 않는다.

### C. 실제 화면과 회귀

8. 재생/일시정지/다시재생/단계 앞뒤 이동/P↔R/OVVO↔Tylko/내부보기/수동카메라 복귀를 조작한다. 이전 모델의 offset·단계 수·카메라 상태가 남으면 수정한다.
9. Tylko 시연은 기존 공식 색상대응→입구→진입→슬라이드→끝선 확인 5단계를 보존한다. 다리 핀 해제나 백패널 동작을 같은 시퀀스로 합치지 않는다.
10. HW 담당에게 연결 캡처와 변환 코드를 보여 기준점 해석을 확인받고, QA에 ASM-CONNECTED와 검증 명령을 게시한다.

## 최소 검증표

| ID | 확인 방법 | 기대 |
|---|---|---|
| ASM-01 | 모든 단계 progress0/0.5/1 직접 호출 | 시간 역이동/재호출 결과 동일, 위치 NaN 없음 |
| ASM-02 | P의 체결/완료 | R 전용 슬라이드 없음, 두 접합점이 같은 계약으로 일치 |
| ASM-03 | R 진입/슬라이드/완료 | 부품 역할·진입 방향 일치, 도면 근거 있는 이동만 사용 |
| ASM-04 | 같은 joint 정면·측면·절단면 | 임의 끝캡/홈 충돌 교정 확인, 미확정 내부기구 별도 표시 |
| ASM-05 | 재생 중 P→R→P | 부품/단계/offset 초기화 정상 |
| ASM-06 | Tylko/백패널 복귀 | 기존12검사 회귀, 다리 해제와 혼동 없음 |
| ASM-07 | 모바일390px 및 데스크톱 | 글자/버튼 가림 없음, 부품 확대/회전 가능 |

정확한 geometry 전체가 없으면 collision-free를 단정하지 않는다. 알려진 메시 모순의 교정과 제조사 실물 내부 구조 확인은 다른 항목이다. 변경 lint·타입·격리 build, 캡처 및 실제 실행 URL을 기록한다.

## 완료 범위

이번 차수는 **OVVO 예제 접합 시연 교정**이다. 실제 주문 전체 판재/접합 순서·다리·영상 내보내기·실제 제조 승인까지 끝났다고 보고하지 않는다. 전체 가구 확장은 리더의 안정 panel ID/접합계획이 실제 연결된 뒤 한다. 그때도 이 부품/pose 모듈을 재사용한다.
