- `manuals/`: 원본 PDF 3개 (조립 53페이지, 낮은 가구 분해 29페이지, 높은 가구 분해 32페이지)

- `images/`: 공식 가이드의 도해·사진 원본 79개.
- `sources.json`, `image-sources.json`, `videos/index.json`: 파일별 출처와 정보.
